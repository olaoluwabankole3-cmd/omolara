# Julius Omolara — Marketing Portfolio

A responsive, motion-enhanced static portfolio built with HTML, CSS and JavaScript for Cloudflare Pages. No framework, package install, environment variables or build tool are required.

## Included
- Responsive navigation, mobile-first layouts, smooth section reveals, animated hero design and a reading-progress indicator.
- Experience entries for Ascent Innovation Lab, Roomz, FUTO BME Research Club, Expedite Crafts and Design, and volunteer data annotation.
- Marketing capabilities and a broad catalogue of common marketing and digital tools. The portfolio does not assign proficiency levels; before publishing, keep only the platforms Julius can confidently use.
- Education entry for the B.Eng. Biomedical Engineering currently in progress.
- Direct email, phone and LinkedIn contact links.
- Interactive marketing, engagement and research concept previews, explicitly labelled illustrative examples rather than completed client projects.
- Basic Cloudflare Pages security headers in `_headers`.

## Deploy to Cloudflare Pages
1. Connect this repository using **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
2. Set `main` as the production branch.
3. Choose **None / No framework** for the framework preset.
4. Set build command to `exit 0` and output directory to `.`.
5. Deploy and inspect the generated `pages.dev` URL on desktop and mobile.
