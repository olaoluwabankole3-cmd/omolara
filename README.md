# Julius Omolara — Marketing Portfolio

An art-directed, editorial-style portfolio for marketing, engagement, brand and research experience. Built with plain HTML, CSS and JavaScript for Cloudflare Pages—no framework or dependency install required.

## Design direction
- Bold editorial typography, paper-like grain, graphic poster artwork and a warm orange/cobalt/ink palette.
- Less card-based layout: narrative sections, an experience index, large concept-art panels and grouped tool categories.
- Lightweight motion: marquee, floating graphic accents, section reveals, and a reading-progress indicator.
- Mobile-first reading flow with a compact navigation menu, vertical experience list, single-column project panels and a bottom contact bar on smaller screens.
- Reduced-motion support, keyboard-accessible concept dialogs, clear focus states and working email/phone/LinkedIn links.

## Content integrity
- Employment dates are omitted because they were not documented.
- The data annotation organisation is unnamed until it can be verified.
- The undergraduate degree is listed as currently in progress; institution not provided.
- Concept previews are marked as illustrative, not completed client work.
- The tool list is a broad industry toolkit, not a verified proficiency assessment. Remove tools Julius cannot confidently discuss or use.

## Deploy to Cloudflare Pages
1. Connect this repository at **Workers & Pages → Create application → Pages → Connect to Git**.
2. Select the `main` production branch.
3. Choose **None / No framework**.
4. Use build command `exit 0` and output directory `.`.
5. Deploy, then inspect the generated `pages.dev` URL on real phones and desktop browsers.
