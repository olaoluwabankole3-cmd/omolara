# Julius Omolara — Marketing Portfolio

An editorial-style portfolio for Julius Omolara, focused on marketing, brand, engagement and research. Built with plain HTML, CSS and JavaScript for Cloudflare Pages.

## Design
- Bold, art-directed hero poster with constrained typography, separate caption spacing and responsive sizing.
- Editorial paper/ink/orange/blue visual system, subtle grain and restrained movement.
- Narrative About section, numbered role list, focused practice areas and richer workbench descriptions.
- Mobile-first layouts: compact navigation, vertically arranged sections, carefully sized poster typography and a persistent contact action near the bottom of smaller screens.
- Keyboard-accessible workbench dialogs, internal-link validation, reduced-motion support, and working email, phone and LinkedIn links.

## Content standards
- Employment dates are omitted because they were not documented.
- The data annotation organisation is left unnamed until confirmed.
- Biomedical Engineering is listed as an undergraduate degree in progress; institution is not provided.
- Workbench copy describes a professional approach and areas of focus. No unsupported client names, campaign outcomes or performance metrics are claimed.
- The toolkit contains common marketing platforms and should be reviewed by Julius so it reflects tools he can confidently use.

## Deploy to Cloudflare Pages
1. Open Cloudflare Dashboard and select **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
2. Connect `olaoluwabankole3-cmd/omolara` and choose the `main` branch.
3. Set framework preset to **None / No framework**.
4. Set build command to `exit 0` and output directory to `.`.
5. Deploy and check the generated `pages.dev` URL on mobile and desktop.

No build dependencies or environment variables are required. The website entry point is `index.html`; static response security headers are in `_headers`.
